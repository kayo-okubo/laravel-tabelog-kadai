# NAGOYAMESHI

飲食店を検索・予約できるWebアプリケーションです。  
プログラミングスクールの卒業課題として制作しました。

## 主な機能

### ユーザー機能
- 会員登録
- メール認証
- ログイン・ログアウト
- パスワード再設定
- 会員情報の確認・編集

### 店舗機能
- 店舗一覧表示
- 店舗名検索
- カテゴリ検索
- 登録日による並び替え
- 店舗詳細表示
- レビュー一覧表示

### 有料会員機能
- Stripeを利用した月額300円の有料会員登録
- クレジットカード情報の変更
- 有料会員の解約
- 店舗予約・予約キャンセル
- お気に入り登録・解除
- レビュー投稿・編集・削除
- 5段階評価

### 管理者機能
- 管理者ログイン・ログアウト
- 店舗の登録・編集・削除・検索
- カテゴリの登録・編集・削除・検索
- 会員一覧表示
- メールアドレスによる会員検索
- 会員詳細表示
